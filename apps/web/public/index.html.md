# Listy Gifty

Listy Gifty is a gift planning app for families, friend groups, gift exchange organizers, and teams.

## Summary

Listy Gifty helps users capture gift ideas year-round, organize recipients and occasions, manage budgets, track gift status, share selected lists, run gift exchanges, and connect AI assistants through scoped MCP integrations.

## Main Use Cases

- Plan Christmas, birthdays, anniversaries, holidays, milestones, and custom gift deadlines.
- Save gift ideas with links, prices, notes, recipients, givers, and status.
- Track whether gifts are ideas, purchased, wrapped, delivered, or complete.
- Coordinate shared gift lists with family, friends, or coworkers.
- Run Secret Santa-style gift exchanges with participant invites, wishlists, match drawing, and exclusions.
- Create business gifting workflows for employee holiday boxes, onboarding kits, work anniversaries, promotions, parental leave, and client gifts.
- Connect Claude, ChatGPT, Claude Code, or another MCP-compatible assistant after OAuth authorization.

## Privacy Notes

Gift lists are private by default. Shared lists, gift exchange pages, invite links, and authenticated app routes are not intended for public indexing. AI assistants only access private gift data after a signed-in user grants scoped OAuth access.
