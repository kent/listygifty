# Spec: Add Kent Fenwick credit to shared Footer

**Ticket:** ef96fd1a — Kent on Footer · live verification
**Target file:** `apps/web/src/components/layout/Footer.tsx`

## Goal

Display a credit to Kent Fenwick in the shared site footer, alongside the existing `ewakened.com` link, without disrupting the current styling or layout.

## Current state

`apps/web/src/components/layout/Footer.tsx` renders a single centered link:

```tsx
<footer className="border-t border-slate-200 dark:border-white/10 py-6 text-center text-sm text-slate-500 dark:text-muted-foreground">
  <a
    href="https://ewakened.com"
    target="_blank"
    rel="noopener noreferrer"
    className="underline hover:text-slate-700 dark:hover:text-slate-200"
  >
    ewakened.com
  </a>
</footer>
```

The Footer is consumed via `apps/web/src/components/layout/index.ts` and rendered on most app pages (home, wishlists, people, exchanges, claim/share pages, etc.).

## Requirements

1. Show "Kent Fenwick" as a credit in the footer.
2. Keep the existing `ewakened.com` link present, working, and visually similar.
3. The two items should read as one line, e.g. `Built by Kent Fenwick · ewakened.com`, with a clear visual separator (middle dot `·`) between them.
4. Match the existing footer typography (centered, `text-sm`, slate/muted colors, light + dark mode).
5. Kent's name should be a link to his personal site, opened in a new tab with `rel="noopener noreferrer"`, using the same underline + hover styling as the existing link.
   - Default URL: `https://kentfenwick.com` (if a different canonical URL is preferred, swap it in — single source of truth in the JSX).
6. No new dependencies, no layout reflow on other pages, no changes to consumers of `<Footer />`.

## Proposed markup

```tsx
export function Footer() {
  return (
    <footer className="border-t border-slate-200 dark:border-white/10 py-6 text-center text-sm text-slate-500 dark:text-muted-foreground">
      <span>Built by </span>
      <a
        href="https://kentfenwick.com"
        target="_blank"
        rel="noopener noreferrer"
        className="underline hover:text-slate-700 dark:hover:text-slate-200"
      >
        Kent Fenwick
      </a>
      <span aria-hidden="true"> · </span>
      <a
        href="https://ewakened.com"
        target="_blank"
        rel="noopener noreferrer"
        className="underline hover:text-slate-700 dark:hover:text-slate-200"
      >
        ewakened.com
      </a>
    </footer>
  );
}
```

## Verification (live)

1. Run the web dev server (`pnpm --filter @listygifty/web dev` or equivalent) and load any page that uses `<Footer />` — e.g. the home page `/`.
2. Confirm the footer reads `Built by Kent Fenwick · ewakened.com`, centered, with both names underlined.
3. Click "Kent Fenwick" — opens `https://kentfenwick.com` in a new tab.
4. Click "ewakened.com" — opens `https://ewakened.com` in a new tab (regression check).
5. Toggle dark mode and confirm both links use the muted/slate color and brighten on hover.
6. Spot-check a second page that mounts the footer (e.g. `/wishlists/[id]` or `/people/[id]`) to confirm no layout shift.

## Out of scope

- Adding social icons, avatar, or copyright year.
- Refactoring consumers of `<Footer />` or the layout system.
- i18n / translation of the "Built by" string.
