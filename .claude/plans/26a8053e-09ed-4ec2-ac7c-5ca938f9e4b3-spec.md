# Pass 1 · Footer © 2026 prefix

## Current state

`apps/web/src/components/layout/Footer.tsx` renders a single `<a>` to `ewakened.com` inside a `<footer>`. Note: ticket describes existing text `'Built by Kent Fenwick · ewakened.com'`, but the actual file only contains the `ewakened.com` link — proceeding with the literal instruction to prefix with `'© 2026 · '` as a new `<span>` at the very start of the footer's children, preserving the existing link.

## Exact JSX change

Insert a new `<span>` as the first child of `<footer>`, immediately before the existing `<a>`:

```tsx
<span>© 2026 · </span>
```

Resulting structure (whitespace-faithful):

```tsx
<footer className="border-t border-slate-200 dark:border-white/10 py-6 text-center text-sm text-slate-500 dark:text-muted-foreground">
  <span>© 2026 · </span>
  <a
    href="https://ewakened.com"
    target="_blank"
    rel="noopener noreferrer"
    className="underline hover:text-slate-700 dark:hover:text-slate-200"
  >
    ewakened.com
  </a>
</footer>
```

No changes to existing classes, link href/rel/target, or surrounding styling.
