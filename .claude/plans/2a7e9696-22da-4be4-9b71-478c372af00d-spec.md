# Footer Bullet Separator Spec

**Context**

The ticket target for `apps/web/src/components/layout/Footer.tsx` renders `© 2026 · Crafted by Kent Fenwick · ewakened.com · made on the canvas` using middle-dot separators.
In the current checkout, `Footer.tsx` only renders the `ewakened.com` anchor and has no `<span aria-hidden>` separator nodes; this plan assumes the implementation target is the ticket-described footer variant.

**Change**

Replace every JSX separator text node that uses ` · ` with ` • `.

Before:

```tsx
<span aria-hidden> · </span>
```

After:

```tsx
<span aria-hidden> • </span>
```

Do this for each affected separator span only, so the visible footer becomes `© 2026 • Crafted by Kent Fenwick • ewakened.com • made on the canvas`. Leave anchor tags, `href` values, and `className` values untouched.

**Verification**

After deploy, verify the production page contains the bullet separator:

```bash
curl -s https://listygifty.com | grep -F '•'
```

**Out of scope**

No anchor, link target, class name, layout, copy, API, mobile, build configuration, or deployment workflow changes are part of this ticket.
